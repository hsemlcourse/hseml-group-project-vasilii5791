## Описание задачи

**Задача:** Регрессия — предсказание цены автомобиля в USD на основе его технических характеристик.

**Датасет:** [Cars Datasets 2025](https://www.kaggle.com/datasets/abdulmalik1518/cars-datasets-2025) (Kaggle)

**Таргет:** `Price` (цена в долларах США)

**Целевые метрики:** MAE (основная), RMSE (дополнительная), R² (справочно)

**Описание:** Датасет содержит информацию об автомобилях различных производителей: объём двигателя/батареи, мощность, максимальную скорость, время разгона 0-100 км/ч, цену, тип топлива, количество мест, крутящий момент. Цель — построить модель, предсказывающую цену автомобиля по его характеристикам.

## Данные

**Источник:** [Kaggle — Cars Datasets 2025](https://www.kaggle.com/datasets/abdulmalik1518/cars-datasets-2025)

**Файл:** `data/raw/Cars_Datasets_2025.csv` (1218 строк × 11 колонок)

**Колонки:**

| Колонка | Описание |
| --- | --- |
| Company Names | Производитель |
| Cars Names | Название модели (удаляется при очистке) |
| Engines | Тип двигателя |
| CC/Battery Capacity | Объём двигателя (cc) или ёмкость батареи |
| HorsePower | Мощность (hp) |
| Total Speed | Максимальная скорость (km/h) |
| Performance(0 - 100 )KM/H | Время разгона 0-100 км/ч (сек) |
| Cars Prices | Цена в USD |
| Fuel Types | Тип топлива |
| Seats | Количество мест |
| Torque | Крутящий момент (Nm) |

**Особенности:** Все колонки в сыром виде имеют тип `object` (строки с единицами измерения, символами валют, диапазонами). Требуется парсинг числовых значений.

**После очистки:** 1214 строк, 10 колонок (удалены дубликаты, колонка Cars Names, числовые значения извлечены из строк, пропуски заполнены).
